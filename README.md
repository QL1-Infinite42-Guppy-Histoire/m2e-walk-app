# M2E Walking App — announcement site

Announcement site for the M2E walking app under development: walk to earn points, unlock them with rewarded ads, and exchange them for gift cards.

- Status (2026-11-16): design complete, development started. The app is **not released yet** — there is no download. Point rates are still being finalized.
- Developed by the community, as part of Guppy's Guide. Not an official app.
